# 基本想法
我想在Finder里面添加一个功能：访问历史
- Finder的左栏，下面，我想显示最近访问过的5条目录。不是文件，是目录
	- 在microNeo里面打开编辑过的文件，则记录这个文件的目录到访问历史中
- 如果Finder太小了，高度低于15了，就算了，不显示这个访问历史了

大约显示成这个样子：
```
---------------------------------------------------
面包屑			|
  子目录		|
  子目录		|
  文件名		|
  文件名		|
				|	file preview
				|
file info		|
----------------|
历史1			|
历史2			|
历史3			|
历史4			|
历史5			|
---------------------------------------------------
```

用户交互方式
- 肯定要区分焦点在哪个区域里，fileSelect区域，history区域，preview区域
- 当焦点在history区域的时候
	- 上下键移动光标，回车或是右键就是切换到这个目录
	- 鼠标上下滚动也可移动光标，点击后光标就在这个目录上，但不切换

这里比较关键的是如何判断和切换焦点，需要第一个讨论的地方。
